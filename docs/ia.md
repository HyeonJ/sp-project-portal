## 4. 진입 동선

### 4-1. 두 가지 로그인 진입 경로 (REQ-AUT-007)

```
[A. 일반 로그인 URL: /login]
    │
    ├─ 관리자 로그인       ──▶ SCR-GLB-001 (전체 프로젝트 목록)
    │                              │
    │                              ├─▶ 관리자 메뉴 (SCR-ADM-001~005)
    │                              └─▶ 프로젝트 선택 ──▶ SCR-PRJ-001
    │
    ├─ 프로젝트팀 로그인    ──▶ SCR-GLB-001 (담당 프로젝트 목록)
    │                              │
    │                              ├─▶ 프로젝트 생성 (SCR-PRJ-002)
    │                              └─▶ 프로젝트 선택 ──▶ SCR-PRJ-001
    │
    └─ 고객사 로그인        ──▶ SCR-GLB-001 (참여 프로젝트 목록)
                                   └─▶ 프로젝트 선택 ──▶ SCR-PRJ-001


[B. 프로젝트별 고유 URL: /projects/{id} 직접 접근]
    │
    ├─ 비로그인 상태       ──▶ /login?redirect=/projects/{id}
    │                              └─▶ 로그인 성공 ──▶ SCR-PRJ-001 (원래 URL 복귀)
    │
    └─ 로그인 상태         ──▶ SCR-PRJ-001 (해당 프로젝트 대시보드 직진)
                                   · 참여 권한 없으면 SCR-SYS-403
```

> 별도의 프로젝트별 로그인 URL은 두지 않음. 단일 `/login` + redirect 파라미터로 처리하는 표준 패턴 채택.

### 4-2. 역할별 주요 작업 동선

**신규 사용자 (초대 수락 첫 진입)**
```
이메일 수신 ──▶ 초대 링크 클릭
            ──▶ SCR-AUT-004 (초대 수락·비밀번호 설정)
            ──▶ 비밀번호 정책 통과
            ──▶ 자동 로그인
            ──▶ SCR-PRJ-001 (참여 프로젝트 대시보드)
```

**관리자**
```
로그인 ──▶ 전체 프로젝트 현황 ──▶ 특정 프로젝트 대시보드
       └─▶ 관리자 메뉴 ──▶ 계정 관리 / 감사 로그
```

**프로젝트팀(PM)**
```
로그인 ──▶ 담당 프로젝트 목록 ──▶ 대시보드
                                     │
                                     ├─▶ 요구사항·산출물 새 버전 만들기 (MOD-VER-001)
                                     │       └─▶ draft 상태에서 파일 추가·교체·삭제
                                     ├─▶ [검토 요청] 발송 (MOD-WF-001, 버전 잠금 트리거)
                                     ├─▶ [개발 시작] (MOD-DEV-001, 사전조건 충족 시)
                                     ├─▶ 프로젝트 설정 ──▶ 팀 멤버·고객사 초대 (SCR-SET-002)
                                     │                       └─▶ 초대 재발송 (MOD-AUT-001)
                                     └─▶ 활동 이력 확인 (SCR-REQ-001·SCR-DSN-001 inline)
```
