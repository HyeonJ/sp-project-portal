### 1-2. REQ-PRJ-004 진행 현황 페이지 표시 영역

대시보드는 **현재** 중심, 진행 현황은 **전체 여정** 중심. 두 화면이 정보를 나눠 갖는다.

| 영역 | 내용 | 비고 |
|------|------|------|
| **KPI 4종** | 전체 진행률 / 통과한 게이트 / 현재 단계 / 다음 메이저 마일스톤 | 모든 역할 공통 |
| **마일스톤 스트립** | M1~M8 가로 스크롤 (요구사항·IA·시안·프로토타입·Figma·개발·UAT·오픈) | 완료/진행/잠금 상태 시각화 |
| **20단계 상세** | 6개 phase 그룹 (착수·요구사항·설계·개발·테스트·이행운영). 각 단계는 노드(원=일반/마름모=게이트) + 단계 번호 + 단계명+세부 + Gate 플래그 + 산출물 링크/상태 뱃지 | 산출물 링크 클릭 시 해당 페이지 이동 |
| **메이저 게이트 강조** | 5·18 단계는 별도 시각 표시 ("Major Gate") | 프로젝트 진행 전체 차단 게이트 |
| **잠금 단계 사유** | 마우스 오버 시 잠금 이유 표시 (예: "Gate 9 통과 후") | 접근성·예측성 |
| **범례** | 노드 색상·게이트 표시 설명 | 페이지 하단 |

**역할별 차이**: 없음 (전부 읽기 전용, 권한 매트릭스의 "전체 프로젝트 조회"와 별개로 자신이 볼 수 있는 프로젝트의 로드맵만 접근 가능).

**의도적으로 두지 않는 항목**:
- 액션 버튼 (검토 요청·컨펌·반려 등) — 대시보드와 산출물 페이지로 이관
- 미처리 항목·최근 활동 — 대시보드에 있음
