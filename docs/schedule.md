## 4. 의존성·블로커

### 게이트 의존 (선행 게이트 통과 필수)
- 9 → 10 (요구사항 확정 없이 설계 진입 불가)
- 11 → 12 (IA 확정 없이 시안 진입 불가)
- 13 → 14 (시안 확정 없이 프로토타입 진입 불가)
- 15 → 16 (프로토타입 확정 없이 Figma 핸드오프 진입 불가)
- 9 ∩ 11 ∩ 13 ∩ 15 → 18 (네 게이트 모두 통과 후 AI 개발 트리거, REQ-DEV-001)
- 22 → 23 (최종 검수 통과 없이 Export 불가)

### 산출물 의존 (선행 산출물 완성 필수)
- IA → 와이어프레임 → 시안 → 프로토타입 → Figma
- IA → ERD (화면 확정 후 도메인 도출)
- ERD + 화면 설계서 → API 명세서
- 아키텍처 + 비기능 요구사항 → 시스템 구성도
- 시스템 구성도 → 배포 가이드

### 블로커 위험
- **반복 루프 폭주**: 7↔8 또는 20↔21이 회차를 다수 반복하면 후속 단계 일정 지연. 합의 기준 명확화 필요.
- **AI 개발 실패**: 18단계 실패 시 재시도 가능(24h당 3회 제한). 3회 실패 시 인적 개입 필요.
- **고객사 응답 지연**: 게이트 컨펌이 지연되면 후속 단계 전체 슬립. SLA 별도 합의 필요.
